# Omi Syndicate

Generative Phrygian Dominant ambient drone synthesizer and 16-step drum machine built with pure Web Audio API and real-time WebGL shaders.

**Live:** https://yunoarasaka.github.io/omi-syndicate/

## Features
- **Interactive Liquid Field:** Real-time WebGL domain-warped fluid shader with thin-film iridescent sheen and audio-reactive luminescence.
- **Harmonic Scale Engine:** Click anywhere on the field to lock a continuous multi-oscillator sustaining pad quantized to **Phrygian Dominant** or any of the **7 diatonic modes** (Ionian, Dorian, Phrygian, Lydian, Mixolydian, Aeolian, Locrian) across all 12 root keys, with strictly in-scale harmonic overtones. Smooth ~580ms morphing between zones, rapid-click polyphonic harmonic layering, and continuous drag glide.
- **Pure Web Audio Synthesis:** Algorithmic stereo convolution reverb, ping-pong diffusion delay, cascaded lowpass filtering, and synthesized Kick / Snare / Hi-Hat 16-step sequencer (60–180 BPM).
- **Zero Dependencies:** Vanilla HTML, CSS, and JavaScript.
